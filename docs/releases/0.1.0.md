# Live Transcribe 0.1.0

Live English transcription for the audio playing on your Mac, using an on-device speech model. This is a small personal utility shared publicly under the MIT license.

## Download and install

- Download **Live-Transcribe-0.1.0-arm64.dmg** below and drag the app into Applications.
- **Apple Silicon only. English speech.** macOS 14.2 is the declared minimum; this preparation build was checked on an M3 Pro with macOS 27.0.1. Older macOS versions have not been validated for this release.
- This build is **ad-hoc signed and not notarized**. If macOS blocks opening it, see the [installation guide](https://github.com/sergiishpak/live-transcribe/blob/main/docs/INSTALL.md#opening-the-initial-release).
- First launch downloads and prepares the speech model. A previous check downloaded roughly **600 MB**. Internet is needed for that download; transcription then runs locally with the cached files.
- Click **Start**, allow system-audio capture, and play English speech. Your microphone is not captured.

## Included

Selectable sentence rows with copy buttons, Start/Stop/Clear, Always on Top, Jump to Live, and backlog skipping. Transcripts remain in memory; copy anything you need before quitting.

## Verification and limits

Checked during preparation on an M3 Pro with macOS 27.0.1 and Swift 6.4:

- All **10 Swift Testing tests** passed.
- A separate clean source copy fetched the pinned dependencies from scratch and built the app without the original build cache or generated output.
- The required build/install script completed; the installed app and release app bundle matched byte-for-byte.
- The installed app reached Ready with its cached model, displayed text while a synthetic English system-audio sample was playing, preserved text on Stop, cleared the transcript, and restarted capture. The Always on Top control was also exercised and restored.
- The DMG passed checksum, mounted-content, app-signature, arm64 architecture, version, and bundled-notice checks.

These cached-model checks do not establish first-download behavior, fresh permission prompts, Gatekeeper approval, or compatibility on every declared macOS version. GitHub Actions has been configured but has not run remotely before publication. Complete any remaining manual checks in [RELEASING.md](https://github.com/sergiishpak/live-transcribe/blob/main/docs/RELEASING.md) before publishing.

No Intel build, microphone capture, saved transcript history, translation, or speaker labeling is included. Accuracy and latency vary with the audio and machine. Maintenance is best effort.

The matching `.dmg.sha256` asset can check download integrity with `shasum -a 256 -c Live-Transcribe-0.1.0-arm64.dmg.sha256`.
