# Changelog

All notable changes to Live Transcribe are documented in this file.

## [Unreleased]

## [0.1.1] - 2026-10-27

### Distribution

- Add validated semantic versioning with major/minor/patch commands and synchronized app, DMG, and checksum versions.
- Prepare the first public Apple Silicon DMG with SHA-256 checksum and package verification.
- Add user, developer, contribution, and release documentation.
- Add MIT licensing for the app and third-party attribution bundled with downloads.
- Add macOS build/test checks and archive the original development plans.
- Move the existing state tests to Swift Testing for Command Line Tools compatibility.

## [0.1.0] - 2026-09-11

### Added

- Local live transcription of macOS system audio.
- Sentence paragraphs with a one-click copy control.
- A packaged app icon and an installer script for `/Applications`.
